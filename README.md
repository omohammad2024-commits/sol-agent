# SOL Agent

ایجنت تلگرامی فارسی‌محور با **TypeScript + Bun + grammY**؛ فقط با زبان طبیعی کار می‌کنه (بدون دستور). مدل: **Claude**، **Gemini** یا هر **پروایدر سازگار با OpenAI** — مثل OpenAI، DeepSeek، Groq، OpenRouter، Mistral، Together، xAI، **OpenCode Zen (رایگان)**، Kimi، Kilo و Cloudflare Workers AI — یا هر **پروایدر کاستوم** با ست کردن `OPENAI_BASE_URL` (با مسیریابی بین مدل ارزون و قوی و جایگزین خودکار).

```bash
bun install
cp .env.example .env     # BOT_TOKEN، کلید LLM، OWNER_ID ...
bun test                 # ۱۱۱ تست
bun run start
```

## قبل از اولین اجرا
1. بات رو بدون `OWNER_ID` یه بار اجرا کن و بپرس «آیدی من چیه؟»؛ عدد رو بذار توی `OWNER_ID` (و `OWNER_NAME`). سازنده **فقط از روی آیدی** شناخته می‌شه.
2. BotFather: `/setprivacy` ← **Disable** (برای صدا زدن با اسم توی گروه)، `/setinline` (حالت اینلاین)، `/setinlinefeedback` ← **Enabled** (برای ویرایش جواب اینلاین).
3. برای ویس، تصویرسازی و TTS کلید Gemini لازمه (یا `OPENAI_API_KEY`).
4. نیازمندی‌های سیستمی: `ffmpeg` (با libopus)، `yt-dlp`. برای اجرای کد در حالت docker: `docker build -t sol-sandbox:latest ./sandbox`.

## چی می‌تونه (همه با حرف زدن)

**حافظه‌ی هوشمند**
- حافظه‌ی بلندمدت با **جستجوی معنایی** (embedding؛ بدون کلید هم با یه embedder آفلاین کار می‌کنه) — فقط چیزای مرتبط با پیام فعلی به پرامپت میرن.
- هر ~۴۰ پیام، گفتگوهای قدیمی به‌صورت خودکار **خلاصه** و ذخیره می‌شن؛ «هفته‌ی پیش درباره‌ی چی حرف زدیم؟» با ابزار `recall` جواب داده می‌شه.

**کارهای زمان‌دار**
- یادآور یک‌باره و تکرارشونده («هر روز ساعت ۸»)، **گزارش روزانه** (هر زمان‌بندی می‌تونه یه دستور برای خود سول باشه)، **هشدار قیمت** («دلار از ۶۵ هزار بالاتر رفت بگو»)، و **کار پس‌زمینه** («برو درباره‌ی X تحقیق کن و گزارش بده»).
- زمان‌بندی‌ها توی دیتابیس‌ان و بعد از ریستارت ادامه پیدا می‌کنن. اجرای بدون‌حضور (scheduled/background) هیچ ابزار قدرتمندی (شل، گیت‌هاب، هدیه...) نداره.

**اسناد**
- خوندن PDF / Word / Excel / PowerPoint / CSV / متن، **OCR** و فهمیدن عکس (فارسی هم)، و ساختن فایل: Word (راست‌به‌چپ درست)، PDF، HTML، Markdown، Excel (با فرمول) و CSV (مناسب اکسل).

**صدا**: ویس ← متن ← جواب؛ اگه سوال ویس باشه جواب هم ویس برمی‌گرده. ابزار `speak` برای «این رو بگو».

**تجربه‌ی کاربری**: جواب به‌صورت **زنده** (استریم) توی یه پیام تایپ می‌شه و وقتی ابزار کار می‌کنه وضعیتش رو نشون می‌ده («🔎 دارم جستجو می‌کنم…»). **حالت اینلاین**: توی هر چتی `@اسم_بات سوالت` بزن.

**گروه**
- جواب فقط وقتی اسمش رو صدا بزنی / تگ / ریپلای.
- **خلاصه‌ی گروه** (فقط وقتی ادمین گروه ذخیره‌ی پیام‌ها رو روشن کرده باشه؛ پیش‌فرض خاموش و باید به اعضا گفته بشه).
- **مدیریت گروه**: خوش‌آمدگویی، ضد اسپم (فلود، تکرار، لینک‌های زیاد، منشن‌های زیاد)، و قوانین به زبان طبیعی که هوش مصنوعی اجراشون می‌کنه (حذف پیام ← اخطار ← میوت). بات باید ادمین گروه باشه. ادمین‌ها معاف‌ان. مثال: «تبلیغات ممنوعه رو قانون گروه کن و مدیریت رو روشن کن».

**ابزارهای قبلی**: قیمت‌ها (ایران/جهان)، وب، ویکی‌پدیا، دیجی‌کالا، DNS، دانلود رسانه، ادیت گیف، تولید تصویر، QR، VirusTotal، گیت‌هاب، Telegraph، هدیه‌ی استارز، اجرای کد (فقط ادمین).

**MCP**: سرورهای MCP رو وصل کن تا ابزارشون (`mcp_<نام>_<ابزار>`) به بات اضافه بشه. سرور محلی (stdio) فقط از فایل پیکربندی (`data/mcp.json`، نمونه: `mcp.example.json`)؛ سرور راه‌دور (URL) هم از داخل چت: «این سرور MCP رو وصل کن: ...». خروجی MCP همیشه «غیرقابل‌اعتماد» حساب می‌شه.

## مدل‌ها، هزینه و پایداری
- **مسیریابی**: پیام‌های ساده با مدل ارزون (`LLM_MODEL_FAST`)، کارهای واقعی با مدل قوی؛ بعد از خطای ابزار یا چند مرحله خودکار به مدل قوی می‌ره.
- **جایگزین خودکار**: اگه سرویس اصلی خطا بده (`FALLBACK_PROVIDER`) می‌ره سراغ دومی و تو پیام می‌گیری.
- **Prompt caching** برای Claude (پرامپت ثابت جدا از بخش متغیر) و کش خودکار Gemini.
- **آمار هزینه**: «هزینه‌ی این هفته چقدره؟» (تخمینی؛ قیمت‌ها توی `src/pricing.ts` و `MODEL_PRICES`، **حتماً با صفحه‌ی قیمت ارائه‌دهنده چک کن**). **سقف روزانه** برای هر کاربر: `DAILY_BUDGET_USD`.
- **اعلان خطا به سازنده** در تلگرام (بدون اسپم: تکراری‌ها ۵ دقیقه، حداکثر ۱۲ پیام در ساعت)، لاگ ساختاریافته‌ی JSON (`LOG_LEVEL`, `LOG_FILE`)، سلامت‌سنج `/health`.
- **بکاپ**: روزانه، فشرده، **رمزنگاری‌شده** (`BACKUP_PASSPHRASE`)، ارسال به تلگرام سازنده و/یا S3 (`BACKUP_S3_*`). فقط بکاپ رمزنگاری‌شده ارسال می‌شه. بازیابی: `BACKUP_PASSPHRASE=... bun run restore data/backups/<file>.db.gz.enc data/sol.db` (اول بات رو متوقف کن).
- **مایگریشن دیتابیس**: خودکار و نسخه‌دار؛ دیتابیس نسخه‌های قبلی بدون از دست رفتن داده ارتقا پیدا می‌کنه.

## مدیریت فقط با حرف زدن
سازنده/ادمین توی چت خصوصی: «قانون جدید: ...»، «آمار و هزینه»، «کاربرا»، «به ۱۲۳ دسترسی بده / بنش کن»، «ابزار X رو خاموش کن»، «پیام همگانی بفرست: ...»، «سرور MCP وصل کن»، «بکاپ بگیر»، «قوانین رو نشون بده».
سلسله‌مراتب: **سازنده ← ادمین‌ها ← trusted ← بقیه**. فقط سازنده ادمین تعیین/بن می‌کنه؛ دسترسی خود سازنده هیچ‌وقت قابل تغییر نیست.

### پنل مدیریت (Telegram Mini App)
با `WEBHOOK_URL` یا `PANEL_URL` (آدرس عمومی HTTPS) فعال می‌شه و دکمه‌ی «پنل» کنار چت ادمین‌ها میاد. احراز هویت با امضای HMAC تلگرام (initData)، فقط ادمین‌ها، محدودیت نرخ، و هدر CSP. صفحه‌ها: نمای کلی، کاربران و دسترسی، قوانین، ابزارها، هزینه، لاگ، بکاپ.

## امنیت
- **سطح‌ها**: public / trusted / admin. کاربر عادی ابزار قدرتمند رو اصلاً نمی‌بینه.
- **نگهبان تزریق**: اگه توی همون نوبت محتوای بیرونی (وب، جستجو، گیت‌هاب، MCP، پیام‌های گروه) خونده شده باشه، ابزارهای قدرتمند (شل، پایتون، نوشتن گیت‌هاب، هدیه، حذف/پین، میوت/بن گروه، تغییر MCP...) تا پیام بعدیِ خودِ کاربر قفل می‌شن. کارهای مدیریتیِ سازنده (بن، پیام همگانی، پاک‌کردن داده) معافن.
- فایل‌ها محدود به پوشه‌ی هر کاربر؛ ضد SSRF؛ پاک‌سازی توکن/کلید از هر خروجی؛ لیست سیاه دستورهای فاجعه‌بار؛ سقف روزانه‌ی هدیه؛ پیوست‌ها بعد از ۲۴ ساعت پاک می‌شن.
- **حریم خصوصی**: ذخیره‌ی پیام گروه فقط با روشن‌کردن ادمین؛ «همه‌ی داده‌های کاربر X رو پاک کن» همه‌چیز (حافظه، خلاصه‌ها، زمان‌بندی‌ها، مصرف) رو حذف می‌کنه.
- سرور MCP محلی با env خالی (بدون توکن بات) اجرا می‌شه.

## چیزهایی که باید بعد از اولین اجرا خودت چک کنی
این‌ها با سرویس بیرونیِ واقعی تست نشدن (شبکه‌ی محل ساخت محدود بود)؛ منطقشون با mock و سرور آزمایشی تست شده، ولی روی سرویس واقعی ممکنه تنظیم کوچیک بخواد:
1. **نرخ بازار ایران** (tgju): کلیدها/واحد (ریال←تومان) رو با سایت مقایسه کن (`IRAN_KEYS` در `src/tools/info.ts`). هشدار قیمت هم به همین وابسته‌ست.
2. **دیجی‌کالا**، **yt-dlp** (اینستاگرام معمولاً کوکی می‌خواد: `YTDLP_COOKIES`).
3. **API های Gemini**: embedding (`gemini-embedding-001`)، TTS (`gemini-2.5-flash-preview-tts`) و تصویرسازی — اسم مدل‌ها ممکنه عوض بشه (`EMBED_MODEL`, `TTS_MODEL`, `IMAGE_MODEL`).
4. **MCP از طریق HTTP** روی سرور واقعی (stdio با SDK رسمی تست شده).
5. **PDF فارسی و `browse`** به Chromium نیاز دارن (`--build-arg WITH_CHROMIUM=true`)؛ بدون اون، PDF فارسی به‌جاش Word می‌فرسته. PDF لاتین با pdfkit تست شده.
6. **S3**، **webhook روی دامنه‌ی واقعی**، **پنل داخل کلاینت تلگرام** (API پنل تست شده؛ ظاهر UI فقط توی تلگرام قابل دیدنه).
7. **قیمت‌ها** (هزینه‌ی تخمینی) رو با صفحه‌ی قیمت چک کن.
8. اجرای اولین بکاپ و **یه بار بازیابی** (`bun run restore`) رو امتحان کن.
